# SVD Designs

Website for SVD Designs: handcrafted maggam and aari work blouses, sarees, lehengas and kurtis.

**Live site:** https://vinjamuribhanuprakash07-png.github.io/svd-designs/

## Files

| File | What it is |
|---|---|
| `index.html` | The website. Everything is in this one file. |
| `assets/svd-logo.jpg` | The logo used on the site (trimmed, web size) |
| `assets/svd-logo-original.jpeg` | The original full-size logo (not uploaded) |
| `old-designs/` | Earlier design versions, kept for reference (not uploaded) |

## Common edits (all in `index.html`)

- **WhatsApp number:** set `SHOP_WHATSAPP`, e.g. `"919876543210"`
- **Products, prices, colours:** the `CATALOGUE` list
- **Custom-quote rates:** `BASE`, `WORK` and `SIZE`
- **Phone, hours, Instagram:** the `<footer>` section

## Updating the live site

Commit your changes and push to `main`. GitHub Pages refreshes the live site within a minute or two.
